## 这是什么？

这是一份面向 **华东师范大学新生（本科生/研究生）** 的非官方「入学攻略 / 生存指南」，由在读的学长学姐共同编写和维护。我们希望帮助新生更快地适应校园生活，少走一些我们当年走过的弯路。

覆盖的内容大致包括：

- 🏫 **入学前准备**：录取后到报到前，你需要做些什么
- 📍 **报到与注册**：流程、材料、注意事项
- 🗺️ **校区指南**：闵行校区、中北校区及周边生活信息
- 🍚 **校园生活**：食堂、宿舍、图书馆、运动场馆、校医院
- 📚 **学业相关**：选课、绩点(GPA)、大类分流、转专业、双学位、交换
- 🎓 **毕业相关**：培养方案、毕业要求、学位授予
- 🧭 **实习 / 科研 / 竞赛 / 出国**：学长学姐的经验与资源
- 🛠️ **实用工具**：校园网、VPN、教务系统、常用 App / 网站入口
- ❓ **常见问题 FAQ**：高频疑问速查

> 📝 上述清单为计划目录，内容仍在逐步整理中。欢迎补充你认为新生需要知道的任何内容！

## 为什么要建这个 Wiki？

官方渠道的信息往往分散在多个部门网站、公众号和通知里，查找起来并不方便。我们把这些经验汇总到一处，方便后来的同学。

**但我们只是学生**，经验可能过时或有误。如果你发现错误，欢迎指出并一起改进。
