# 华东师范大学新生攻略 Wiki

> **ECNU-Wiki** —— 由华东师范大学在读学长学姐自发维护的非官方「入学指南 / 生存 Wiki」。站点风格参考 [cdk-eks-blueprints](https://awslabs.github.io/cdk-eks-blueprints/)。

!!! warning "非官方项目声明"

    本站由在校学生自发编写与维护，**与华东师范大学及其任何官方机构、院系、组织均无隶属或合作关系**。
    站内所有内容均为个人经验整理，仅供参考，不构成任何官方指引、承诺或法律意见。请务必以学校及各职能部门的最新官方通知为准。
