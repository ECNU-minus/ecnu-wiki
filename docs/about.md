# 关于本站

**ECNU-Wiki** 是一份面向华东师范大学（ECNU）新生与在校生的**非官方**入学指南 / 生存 Wiki，由在读的学长学姐们自发编写与维护。

## 为什么有本站？

官方渠道的信息常常分散在多个部门网站、公众号和通知里，查找起来并不方便。我们希望把这些年的经验汇总到一处，让后来的同学少走弯路、更快地适应校园生活。

无论你是本科生还是研究生，都可以在本站按 [分类导览](index.md) 查找相关内容，也可以阅读 [如何贡献](contribute.md)，一起把这份 Wiki 做得更好。

## 由谁维护？

本站由 **ECNU 在校学生 / 校友志愿者** 共同维护。任何人都不是唯一作者——内容来自一届又一届同学的经验沉淀。

维护方式与约定请见：

- [如何贡献](contribute.md)
- [免责声明与版权](disclaimer-license.md)
