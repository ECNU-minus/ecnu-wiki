# 如何贡献

首先感谢你愿意帮助维护 ECNU-Wiki！🎉

本站采用开放的协作方式：任何 **华东师范大学（ECNU）的在校生或校友** 都欢迎参与。也欢迎其他了解相关信息的人参与校对和补充，但请以 ECNU 师生的实际经验为准。

## 你可以做什么？

- 📝 **补充内容**：整理你亲历的、对新生有用的信息
- ✏️ **校对勘误**：指出过时、有误或表述不清的地方
- 💡 **提出建议**：在 GitHub [Issues](https://github.com/ecnu-wiki/ecnu-wiki/issues) 里提出你想增加的话题
- 🧹 **整理结构**：优化目录、排版、可读性

## 内容约定

为了让内容可靠、好维护，请遵循以下约定：

1. **强调非官方**：所有内容均为个人经验整理，不代表学校立场。涉及政策、规定时，**必须**标明信息来源并注明「以官方通知为准」。
2. **注明时效**：政策、地点、费用等信息会变化，请在相关条目注明「截至 YYYY-MM」等信息。
3. **避免主观负面评价**：描述事实与经验即可，不要对院系、老师、同学进行贬损性评价。
4. **引用官方来源**：能附上官网、公众号、教务系统等官方链接的，尽量附上。
5. **文件命名**：使用清晰、简短的小写文件名，具体组织见各分类目录。

!!! tip "先看站内样例"

    具体的文档目录结构与现有骨架，可先在 9 个[分类页面](index.md) 与各页面的「待补充主题」中查看，照着已有格式补充即可。

## 提交流程（GitHub Flow）

1. **Fork** 本仓库并 clone 到本地。
2. 创建分支：`git checkout -b feat/add-courses`。
3. 做出修改并提交，提交信息用简洁的中文或英文描述即可。
4. **推送分支并提交 Pull Request**，在 PR 描述里简要说明改动内容。
5. 等待维护者 review，可能需要补充或调整。
6. 合并后，改动即进入主分支。

> 如果只是做很小的修改（比如一个错别字、一个错误链接），也可以直接在网页上编辑并提交 PR，不必走本地 fork 流程。

## Issue / PR 模板要点

提交 Issue 或 PR 时，请尽量说明：

- 你希望补充 / 修改的话题
- 相关信息的来源或你的经验背景
- 是否涉及时效性（如果是，附上大致时间）

## 许可说明

仓库根目录还配有 [行为准则](https://github.com/ecnu-wiki/ecnu-wiki/blob/main/CODE_OF_CONDUCT.md) 与 [贡献指南](https://github.com/ecnu-wiki/ecnu-wiki/blob/main/CONTRIBUTING.md)（本项目级元文件）。

一旦你提交 PR，即表示你同意将你的贡献以本仓库采用的 **CC BY 4.0** 协议发布。如有异议，请勿提交。完整说明见 [免责声明与版权](disclaimer-license.md)。
