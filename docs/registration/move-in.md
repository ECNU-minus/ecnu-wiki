# 进校、入住与校内交通

## 什么时候能进学校？什么时候能入住宿舍？

华师大只要刷身份证就能进校，没带身份证也可以在保安处扫微信二维码登记入校；

**只要你可以激活使用 ECard（一般要在统一身份认证可以登录之后）**，你就可以凭借校园码验证身份而作为校内学生进校。

宿舍**只能**在报到日前一天入住。我也**建议你提前一天**，因为报到日那天人爆多（头一天人也很多，但没有那么多那么热闹<del>吵闹</del>）。**按照学校规定，是不能申请临时宿舍的。**

> [华东师范大学学生宿舍临时住宿管理办法（试行）](https://xxgk.ecnu.edu.cn/e2/f2/c11949a320242/page.htm)节选：
>
> **第十条** 以下情况不受理临时住宿申请：
>
> （一）已拿到录取通知书但尚未报到注册的准新生。
