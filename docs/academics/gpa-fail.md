# 挂科与四六级

## 挂科的后果？

> 挂科：总评分数未达 60 分。

无法参评下一学年度奖学金；该学年无法参加入党推优，不具备入党推优资格；给你留下一个挂科记录；如果没有通过补考，还需要**重修**这门课程，并交上一学分 175 元的重修费（毕业结算）。

一般来说，能把自己玩挂科，甚至多门挂科，都是神人了。一般不需要焦虑这个，总得学一点。

> 补充：4+2 公费师范生的推免政策可能会有不挂科这一条，请尽量不要挂科！

## 四六级重要吗？

**省流：不太重要。但对于保研来说，你还是需要一个 solid 的六级成绩。**

四级考试我认为一般通过就行，高分段容错太小；**六级考试有一定含金量，建议认真对待。**

保研需要以四六级成绩作为依据。

> 来自一位保研去了复旦的学长：
>
> 很多学校卡六级，隐形卡。感觉尤其是复旦的文科和经管，理科也会卡。
>
> 总之六级还是要考高的。尽量 500+ 最好。

不要把宝贵的青春浪费到大量的重复性工作上；**谨防卖四六级备考课的"好心学长学姐"。**

**关注部分学院强制要求四六级。**
