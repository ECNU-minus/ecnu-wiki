# 学校的银行卡

录取通知书会随附一份银行卡办理通知。扫描上方二维码，方可在开学时领取**学校限定卡面**的中国工商银行银行卡（过了这个村没有这个店），它会自动与你关联，用于学费等代扣缴（没啥用），奖助学金发放等等（这倒是提醒我了）。如果没有关联可用的工行卡，你会收不到财务处打给你的奖励和劳务费之类的。

如果没有来得及办理，或者你已经有工行卡了，怎么办？很简单，在财务系统中将一张工行卡与你关联就好了。具体可咨询财务处。
