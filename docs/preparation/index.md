# 入学前准备

本分类面向 **录取后到报到前** 的同学，将收录这段时间需要完成的线上 / 线下手续、要准备的材料，以及需要留意的时间节点与注意事项。

!!! info "内容待补充"

    本章正在编写中。欢迎参考 [如何贡献](../contribute.md) 补充你的经验。

## 本分类将收录

- 录取通知书、档案与材料核对
- 线上手续（信息登记、缴费、选宿舍等）
- 交通与临时住宿安排
- 入学所需证件与物品清单
- 到校前的常见疑问
