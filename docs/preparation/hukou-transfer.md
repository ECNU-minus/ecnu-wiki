# 户口迁移

只允许非沪籍考生迁移，且必须在入学时完成迁移，逾期不予迁移。具体见迎新系统。

## 优点

- 如果你本来不属于部分使领馆的上海领区，这会让你的签证办理更加便捷。（？）
- 可以重新办一张写着上海地址的身份证。
- 说点不中听的：如果你真的想逃离家里（切割），并且真的可以在大学四年实现经济独立，并且也不是公费师范，那这算是必要的第一步了。

## 缺点

- 直到本科毕业前，只要你要户口本本人页复印件，就要到学校保卫科。这会增加你的办事成本。
- 如果你是农村户口，迁出户口将非常亏。
- 落户学校的集体户口和落户上海毫无关系。

总之，迁移户口与否是需要你自己考虑清楚的。
