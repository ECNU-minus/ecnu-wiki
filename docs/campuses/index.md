# 校区指南

华东师范大学目前有**闵行校区**（主校区，本科生与研究生主要园区）、**普陀校区**（即「中北校区」，中山北路3663号）等校区，临港新校区已于 2025 年 1 月获批建设。本分类带你快速认识各校区与往返交通。

!!! info "本页导航"

    - [**闵行校区**](minhang.md) —— 功能分区、教学楼与食堂、校门、交通接驳
    - [**中北校区**](zhongbei.md) —— 普陀校区的设施、校门沿革与交通
    - [**两校区往返交通**](transport.md) —— 校车班次、地铁路线、公交与打车

- 各校区平面图与区位图已内嵌在对应子页中

## 几个常见的「校区误区」

- **中北校区 = 普陀校区**：官方现称「普陀校区」，地址中山北路3663号，老生习惯叫「中北」
- **15 号线没有「华东师范大学站」**：去闵行校区请认准 **紫竹高新区站**（详见[往返交通](transport.md)）
- **两校区之间的校车是工作日班次**（6:30 / 11:50 / 16:50 / 21:00），且优先保障教职工，学生可乘空余座位
